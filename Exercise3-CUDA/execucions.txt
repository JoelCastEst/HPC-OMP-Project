# This file contains all CUDA execution commands used in the experiments
# Command format:
# ./cudaconv <image-file> <kernel-file> <output-file> <partitions> <blockX> <blockY>
#
# Parameters:
# <image-file>  : input PPM image
# <kernel-file> : convolution kernel file
# <output-file> : resulting output image
# <partitions>  : compatibility argument kept from previous versions
# <blockX>      : CUDA block size in the X dimension
# <blockY>      : CUDA block size in the Y dimension
#
# Standard output is redirected to a log file in order to save execution times
